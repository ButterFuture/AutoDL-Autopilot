<p align="center"><img src="assets/demo.cn.svg" alt="一次运行：预算核对、开机、运行任务、关机、记账，历时 8 分 47 秒，费用 ￥0.14" width="830"></p>

- **不空转**：任务结束或实例空闲即关机（有卡空闲 15 分钟，无卡 60 分钟，方便慢慢下载），对话中断也照样生效。
- **不用开浏览器**：开关机、定时关机、读账单都直接调用控制台接口，几秒完成。
- **花多少心里有数**：每次开机前过预算关口，账本以控制台账单为准。
- **不开机传数据**：文件存储的上传、下载、删除都直接走控制台，实例关着也能传，不花 GPU 和无卡的钱。
- **帮你挑机器、租机器**：按型号、地区、空闲卡数、单价、CUDA 版本查算力市场（约 1 秒），主机没卡时列出同型号的其他机器；选好后租用，每次下单前都先经你同意。

## 快速开始

**1. 安装**（目前面向 Claude Code，Codex 版本将在后续提供；本机需要 Python 3.8+ 与 OpenSSH）

```bash
git clone https://github.com/ButterFuture/AutoDL-Autopilot ~/.claude/skills/autodl-autopilot
```

**2. 存控制台令牌**

在已登录的 AutoDL 控制台按 F12，运行 `copy(localStorage.token)`；再在自己的终端里运行下面的命令，粘贴后回车。令牌不会进入对话。

```bash
~/.claude/skills/autodl-autopilot/bin/autopilot token set
```

**3. 告诉 AI 用它**

```
这个项目的实验在 AutoDL 上跑，用 autodl-autopilot 管开关机
```

AI 会生成专用 SSH 密钥，第一次连接时自动把公钥装到实例上，不用你去控制台粘贴；再问清实例 ID、有卡与无卡的用法、预算和空闲多久关机，设置写进项目的 `CLAUDE.md`。之后直接说需求即可，也可以输入 `/autodl-autopilot` 调用。

| 你说 | 它做 |
|---|---|
| 把训练跑起来 | 核对预算，有卡开机，启动守护程序和任务 |
| 把数据传上去，传完就关机 | 无卡开机（每小时 0.1 元），传完关机并记账 |
| 这个月还剩多少预算 | 读本机账本，不开机 |
| 内蒙有没有空的 4090，2 块钱以内 | 查算力市场，按价格列出有空闲卡的机器 |
| 把 data 文件夹传到内蒙的文件存储 | 不开机，直接上传到文件存储，实例里在 `/root/autodl-fs` 下可见 |
| 就租第一台，两张卡 | 先给出方案（机器、单价、镜像、预计花费），你同意后才下单，开好后照常装守护 |

## 工作方式

<p align="center"><img src="assets/arch.cn.svg" alt="架构：你把需求告诉 AI；AI 经 skill 调用本机的 autopilot；autopilot 经控制台接口开关机并读账单，经 SSH 在实例上运行任务；实例上的守护程序空闲即关机" width="830"></p>

- **autopilot** 是本机的命令行工具，AI 的每一步操作都经过它，开机前先过预算关口。
- **控制台接口**负责开关机、定时关机、余额与账单；SSH 地址也从这里读，不用自己配置主机别名。
- **SSH** 负责在实例上运行任务、传文件、正常关机。每条命令先核对主机名，连错机器就什么都不做。
- **守护程序**运行在实例的数据盘上，按 GPU、CPU 与网络的实际占用判断空闲，不依赖对话是否还在。

## 费用与安全

<p align="center"><img src="assets/safety.cn.svg" alt="三道防线：预算关口、守护程序、控制台定时关机" width="830"></p>

- **开机先设兜底**：每次开机前先在控制台设一个 30 分钟后的定时关机，守护程序就位后才取消。即使开机后对话立刻中断，实例也会被平台关掉。
- **公钥自动装到实例上**：实例拒绝密钥时，用控制台显示的 root 密码登录一次，把公钥追加到 `/root/.ssh/authorized_keys`，之后都用密钥。密码不显示、不保存、不进命令行；不想这样可以关掉，改为在控制台“设置SSH免密登录”。
- **令牌只由你本人保存**，位于 `~/.config/autodl-autopilot/credentials`（权限 0600），锁屏、息屏、SSH 会话里都能用；AI 不读取也不显示它。
- **只做开关机与租用这一类事**：开机、关机、定时关机、读余额与账单、查算力市场、按量租用。释放、重置、克隆、充值、续费等操作，代码里没有。租用前一定先给你看方案，你同意后才下单。
- **控制台接口并非官方公开 API**，而是 AutoDL 网页自己使用的接口，平台改版可能失效，届时命令会明确报错。
- 长时间低占用的任务（等数据、休眠）请事先告诉 AI，它会先保持实例，免得被当成空闲关掉。

## 常见问题

<details>
<summary><b>没有空闲 GPU 怎么办？</b></summary>

关机后 GPU 不保留，再开有卡时主机上的卡可能已被占满。AI 会告诉你并隔几分钟重试；只需传数据或改代码时，可以先用无卡模式。
</details>

<details>
<summary><b>实例上会留下什么？</b></summary>

数据盘上的 `/root/autodl-tmp/.autopilot/`：守护脚本、任务日志与状态；系统盘上只在 `/root/.ssh/authorized_keys` 里加一行公钥。守护程序由 autopilot 在每次开机后启动，你自己在控制台手动开机时没有守护。
</details>

<details>
<summary><b>某个进程空闲时也不想被关，怎么办？</b></summary>

告诉 AI 把它加进白名单并给出时效，例如“Jupyter 保留 7 天”。在时效内只要该进程还在，实例就不会因空闲被关机；时效一过自动失效。没加白名单的进程按默认逻辑处理：只看 GPU、CPU 与网络的实际占用，进程空挂着不算忙。
</details>

<details>
<summary><b>能不能默认不开守护，只给某台机器开？</b></summary>

可以。让 AI 把守护的默认设置改为关闭，再对需要的那台机器单独开启即可；反过来也能对单台机器关闭。关闭守护的机器开机后不会自动关机，需要你或 AI 手动关。
</details>

<details>
<summary><b>实例长期不用会怎样？</b></summary>

按平台规则，连续关机 15 天的实例会被释放、数据清空。AI 读到释放日期不足 3 天时会提醒你。
</details>
